# 写真で一日をふりかえる

ピンときた写真を手がかりに、一日を前向きな物語にしてふりかえる内省アプリ（PWA）。

## 体験の流れ

1. **朝・昼・夕方**：ランダムに並んだ写真から、それぞれの自分にピンときた1枚を選ぶ
2. 各写真に「**この写真と、あなたのどこが重なりましたか？**」と答える（任意で前向きな言いかえも）
3. **今日の物語**：3枚を並べて眺め、今日を1本のストーリーにまとめる
4. **明日の1枚**：明日を思わせる写真を選び、明日やることを決める
5. **きろく**：4枚と物語をカードで残す

夜にまとめてふりかえる想定なので、問いはすべて過去形。

## スマホへのインストール（Android）

1. Chrome で公開URLを開く
2. メニュー（︙）→「アプリをインストール」（または「ホーム画面に追加」）

ホーム画面のアイコンから全画面で開ける。一度開けば、電波がなくても記録は見られる（新しい写真を選ぶときだけネットが必要）。

## 記録の保存

- 記録と選んだ写真は**端末の中（IndexedDB）だけ**に保存する。サーバーには送らない
- 「記録の保存」から、記録を写真ごと1つのJSONファイルに**書き出し／読みこみ**できる（機種変更やバックアップ用）
- ブラウザのサイトデータを消すと記録も消えるので、ときどき書き出しておくと安心

## 写真について

- [Lorem Picsum](https://picsum.photos) の全写真リスト（約1,000枚）からランダムに8枚出す（スマホは2列×4段、PCは4列×2段）。元の写真は [Unsplash](https://unsplash.com) のもので、Unsplash ライセンス（商用利用可）
- キーワード検索はしない。「なぜこの写真にピンときたのか」をこじつけで考えること自体が、リフレーミングの入り口になるため
- 同じ日の中では、選んだ写真は二度と出さない。一度見せた写真も、候補が尽きるまでは出さない
- 撮影者名と元ページへのリンクを表示する

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `css/style.css` | 画面 |
| `js/app.js` | 画面の状態と描画。フレームワークなしの素のJS |
| `js/photos.js` | Picsumの写真リスト取得とランダム選択 |
| `js/records.js` | 記録の形の統一、日付の表示 |
| `js/db.js` | 端末内（IndexedDB）への保存 |
| `js/backup.js` | 書き出し／読みこみ |
| `sw.js` / `manifest.webmanifest` / `icons/` | PWA（オフライン対応、インストール）。アイコンの元絵は `icons/icon.svg` |

サーバーを持たない静的サイトなので、GitHub Pages などにそのまま置ける。

## 開発

```bash
npm start   # http://localhost:8080 で確認
npm test    # テスト（Node.js 20 以上）
```

外部ライブラリは使っていない（`npm install` 不要）。
